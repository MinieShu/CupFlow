## E. 记录原则

1. 试用前后使用同一类饮品、同一时段和相近人员条件进行对比，并注明差异。
2. 视觉提示均需人工复核；应同时记录误报、漏报和无法判断案例。
3. 不以空白模板、单个演示订单或未复核日志替代真实效果证据。
4. 如涉及真实门店/员工/订单，按 `DATA_COMPLIANCE_NOTE.md` 执行现场告知、权限控制和最小化采集。

## E. 记录规则

- 仅记录与流程验证有关的最少信息；订单号和人员姓名使用匿名编号。
- 不拍摄顾客面部、支付页面、会员页或人员私人物品。
- 如实记录识别失败、连接中断和人工介入情况，不只保留成功记录。
- 对外使用前，移除可识别场所与个人信息，并取得必要确认。

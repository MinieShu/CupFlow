# CupFlow 项目说明

CupFlow 是面向奶茶门店一线制作的 AI 眼镜流程辅助系统。它将订单约束、配方步骤、第一视角识别、异常提醒和本地记录组合为一次一个订单的制作闭环。

## 场景与问题

奶茶制作的订单、配方、小料、杯贴与现场动作分散在不同位置。新人需要记忆配方并反复核对订单；忙时容易出现错加、漏加、步骤顺序不当或杯贴不符。CupFlow 将当前订单转化为可执行步骤，在制作第一视角只给出必要提示。

## 工作闭环

```text
订单输入（杯贴扫描 / 预留 POS 接口）
  → 配方与订单选项匹配
  → 动态生成制作步骤
  → 店长端下发至眼镜
  → 第一视角识别与步骤提示
  → 正常自动续步 / 异常提示与本地记录
  → 纠正后继续当前订单
```

订单没有专门配方时，系统按制作语义安排加料：珍珠、椰果、仙草、布丁、芋圆、红豆、西米等杯底小料位于“取杯”后、“加入茶底”前；芝士、奶盖、奶油等顶部加料位于“核对液位”后、“扣紧杯盖”前。显式配置的配方步骤优先。

## 核心功能

1. **订单理解与下发**：店长端录入或扫描杯贴，识别订单号、饮品、糖冰和加料，匹配配方后下发至一副眼镜。
2. **动态步骤编排**：根据订单和配方生成实际步骤；眼镜端显示手机端下发的真实步骤，不使用固定流程。
3. **实时流程识别**：手机 Companion 通过 CXR-L 接收眼镜第一视角关键帧，调用视觉服务识别取杯、加茶底、加小料、定量、扣紧杯盖与杯贴核验。
4. **格架辅助判断**：带标签的独立物料直接读取标签；对于分格小料，店长可配置多个行列格架和可选基准图。只有在格架与格位可靠时才辅助判断，无法确认则不推进。
5. **低打扰眼镜交互**：眼镜端以黑底常亮和三行字幕显示订单、当前步骤与必要提醒；制作中不能通过触摸跳过视觉校验。
6. **异常留证与恢复**：错料、液位或杯贴异常会推送到眼镜并记录手机本地关键帧；纠正后自动恢复当前订单的识别。

## 技术结构

| 层 | 实现 | 职责 |
| --- | --- | --- |
| 眼镜端 | Kotlin、Rokid CXR-S | 接收订单和动态步骤，显示最少字幕、TTS 和异常提醒 |
| 店长端 | Kotlin、Rokid CXR-L | 连接眼镜，管理订单、配方、格架和异常，接收第一视角关键帧 |
| 视觉服务 | 服务端 `/api/vision` | 输出结构化操作事件、置信度、原因和识别来源 |
| 规则状态 | 订单约束与状态机 | 低置信度不推进；异常保持当前步骤，纠正后继续 |

## 部署边界

- 本地调试使用 Mac、USB ADB reverse 和本地视觉服务。
- 正式门店应使用 HTTPS、受控网络或边缘节点，并配置鉴权、日志和访问权限。
- POS 目前预留订单字段和接入边界；接入具体厂商前需要取得接口与数据处理授权。
- 系统提供操作辅助和异常记录，不替代门店 SOP、食品安全制度和人员的最终确认。

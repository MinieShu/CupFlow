# CupFlow 测试流程

本流程用于使用真实杯具、杯贴、小料和分格架完成一次单订单验证。

## 准备物品

- 已安装 CupFlow 的 Rokid 眼镜与 Android 店长手机，Mac 本地视觉服务和 USB 数据线。
- 杯贴：订单号、饮品、糖冰和加料清晰可见。
- 透明制作杯、杯盖、量杯或刻度、珍珠/椰果等小料容器，以及带标签的独立物料容器。
- 手机端已配置相应饮品配方和小料格架；独立物料保持可见标签。

## 开始前确认

1. 启动本地视觉服务，建立 `adb reverse tcp:3000 tcp:3000`。
2. 手机与眼镜在 Rokid AI App 中授权并连接，眼镜已导入最新版 APK。
3. 杯贴的饮品名与手机端配方名一致，格架行列与实际摆放一致。
4. 先用同一套道具完成一次检查，再开始正式测试；过程中不要变更配方或格位。

## 验证顺序

1. 在店长端扫描或录入订单并下发。
2. 确认眼镜显示订单和第一步，轻触“开始制作”。
3. 按当前步骤取杯、取用正确小料、加入茶底并观察是否自动进入下一步。
4. 在小料步骤故意拿取不匹配物料，确认眼镜显示异常提示，手机端出现本地异常记录。
5. 放回错误物料并完成正确操作，确认系统继续当前订单且不需要手动跳步。
6. 完成定量、顶部加料（如订单要求）、扣紧杯盖和杯贴核验。
7. 在手机端检查异常记录是否包含订单、时间、操作员、异常类型与关键帧。

## 异常处理

- 视觉服务不可用时：停止自动判断，保留订单、配方与格架配置，检查服务地址和网络连接。
- 眼镜连接中断时：在手机端重新连接后重新下发当前订单，不把未确认步骤标记为完成。
- 杯贴识别置信度不足时：重新拍摄，不自动下发不完整订单。

# CupFlow 数据与隐私说明

## 数据范围

| 数据类型 | 使用方式 | 保存与边界 |
| --- | --- | --- |
| 订单与配方 | 生成当前制作步骤 | 使用最少订单字段，不接入支付、会员或联系方式 |
| 杯贴与制作台图像 | 实时识别当前步骤 | 仅在授权区域采集，视觉服务不持久化普通关键帧 |
| 格架配置与基准图 | 辅助识别小料格位 | 基准图可选，仅在当次识别请求中作为上下文 |
| 异常关键帧与记录 | 用于本地复盘 | 保存在手机本地，应配置期限、访问权限和删除方式 |
| POS 订单 | 预留接入 | 接入前应取得门店、厂商和数据处理授权 |

## 使用边界

1. 使用前应告知相关店员摄像头用途、保存范围、访问人员和删除机制，并取得必要授权。
2. 不采集顾客面部、支付页面、会员信息、联系方式或与制作任务无关的画面。
3. 低置信度、视觉不可用、食安或过敏原提醒、配方冲突和设备异常均不自动放行，由店员或店长确认。
4. 系统用于操作辅助和异常记录，不替代食品安全制度、门店 SOP、顾客沟通或管理决策。
5. 本地 USB 服务只适用于受控开发环境；正式部署应使用 HTTPS、鉴权、日志审计和权限分级。

## 删除建议

- 异常证据仅保留满足培训复盘需要的最短期限，期满后删除。
- 店长端应支持按订单或日期查看与删除；导出前遮蔽无关人员或顾客信息。
- 如需将数据用于模型改进，应另行取得授权，并与实时运行数据隔离。

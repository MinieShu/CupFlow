# CupFlow 眼镜交互与视觉地址设计

## 目标

让眼镜端可以使用自身麦克风启动制作，保持纯黑沉浸式显示，并允许店长端在 USB 本地调试与 HTTPS 部署服务之间切换。

## 设计

- 眼镜端申请 `RECORD_AUDIO`，使用系统语音识别监听“开始”“开始制作”等指令。识别成功后由眼镜端发出既有的 `cupflow_started` 事件；语音服务不可用时保留轻触入口。
- 眼镜端在启动及重新获得窗口焦点时隐藏状态和导航界面，保持黑底字幕显示。
- 店长端默认地址为 `http://127.0.0.1:3000/api/vision`，用于 `adb reverse` USB 调试；店长可在应用内修改地址。本机外的服务地址必须是 HTTPS，地址无效时不保存。

## 验收

- 待开始订单可由眼镜麦克风识别“开始制作”并进入制作状态。
- 眼镜端不显示应用库、状态栏或导航层。
- 未配置时仍使用 USB 本地地址；保存 HTTPS 地址后后续视觉请求使用新地址。

# 数据来源与合规说明

## 数据类型与来源

| 数据 | 来源 | 使用方式 | 保留方式 |
| --- | --- | --- | --- |
| 演示订单、配方与定制项 | 项目自建模拟数据 | 驱动工作流与杯贴比对 | 源码内版本化示例 |
| 第一视角关键帧 | 店员主动授权的演示摄像头 | 发送至已配置的视觉模型服务做单次识别 | 浏览器内存；服务端不持久化原始图像 |
| 异常前后片段 | 浏览器 MediaRecorder | 仅用于当前会话下载复盘 | 默认内存滚动缓存 |
| 模型调用 Trace | 系统生成 | 记录工具、来源、耗时和 token 用量 | 当前会话展示；本版本不做持久化 |
| Android 眼镜关键帧 | 用户主动触发的设备摄像头 | 通过服务端 API 进行单次识别 | 眼镜端不持久化；演示时仅使用经授权画面 |

## 安全边界

- 系统不控制封口机、加热设备、配料设备或其他实体设备。
- 系统不替代门店 SOP、食品安全制度、店长或店员的最终判断。
- 低置信度或无法识别时，系统保持当前步骤，不自动放行。
- 液位超标和杯贴不匹配属于高风险事件，必须经过店员人工复核。
- 演示不得采集顾客人脸、支付信息、真实订单隐私或未获授权的门店画面。

## 提示注入与模型风险

杯贴、订单纸条和画面文字都按不可信数据处理。视觉模型被要求只返回 JSON；服务端校验事件枚举、置信度范围、图像格式和文本长度，并对杯贴字段进行确定性比对。模型输出不直接触发实体动作。

## 商业 API 披露

本项目可使用商业视觉模型 API。参赛材料应写明模型供应商、模型版本、调用范围、费用假设和可替代方案。当前接口遵循 OpenAI Chat Completions 兼容格式，可替换为其他兼容服务；迁移成本主要是模型名称、API 地址、鉴权和视觉效果回归测试。

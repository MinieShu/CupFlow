# CupFlow 评测与成本治理

## 可重复策略评测

启动服务后访问：

```text
http://localhost:3000/api/agent/evaluate
```

评测套件 `CupFlow policy-eval v1` 覆盖五类确定性场景：正确取杯、低置信度、错加小料、重复加料、错误杯贴。每个场景验证预期策略结果是“推进、保持或复核”。

## 视觉评测建议

对于每种物料、杯贴和异常，应以经授权的演示图像分别记录：样本数、正确识别数、错误推进数、低置信度拦截数、平均响应时间和人工复核次数。不得把演示成功率表述为真实门店总体准确率。

## 成本治理

- 仅在画面变化或最长 7 秒复检时上传关键帧。
- 同一画面最短调用间隔为 2.4 秒。
- 连续两次策略通过才推进步骤，减少单帧误判。
- 若供应商返回 token 用量，Trace 显示 token 与耗时。
- 可在 `.env.local` 配置 `VISION_INPUT_COST_CNY_PER_1K_TOKENS` 与 `VISION_OUTPUT_COST_CNY_PER_1K_TOKENS`，以显示单次调用估算费用；未配置价格时不虚构金额。

## 上线前检查

1. 为模型服务设置调用额度、超时、重试和告警。
2. 按门店实际 SOP 由授权人员维护配方知识库与版本。
3. 对镜头位置、光照、杯贴版式和异常样本完成回归测试。
4. 审核数据授权、隐私告知和第三方 API 服务条款。
